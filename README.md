# 🧠 Second Brain — MERN Productivity App

A full-stack knowledge management application that helps users store, organize, and share digital content such as notes, articles, videos, and personal resources.

---

## 🚀 Features

- 📚 Capture and organize articles, videos, and external resources  
- 🔐 Secure authentication using JWT  
- 🔗 Share Brain — Generate unique, secure shareable links  
- 🧩 Fully responsive UI built with React + Tailwind CSS  
- 🔄 Real-time interactions with reactive UI components  
- 🛡️ Protected routes with token verification middleware  
- 🟦 End-to-end type safety using TypeScript

---

## 🛠️ Tech Stack

**Frontend:** React, TypeScript, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB + Mongoose  
**Auth:** JWT, Middleware  
**Deployment:** Vercel / Render
